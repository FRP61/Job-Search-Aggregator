# Переход на публичный репозиторий

[English](PUBLIC_RELEASE.md) | **Русский**

Что сделать, когда проект готов стать публичным. На момент проверки секретов в истории коммитов не было:
пароль `jobs` в `docker-compose.yml`, `.env.example` и CI относится только к локальной базе.

## Обязательно

- [ ] **Выбрать лицензию** и добавить `LICENSE`. Без неё другие не могут законно использовать код, даже если он публичный.
- [ ] **Договориться с напарником:** оба автора должны согласиться на публикацию и лицензию.
- [ ] **Проверить условия использования каждого источника:** EURES, Bundesagentur, cv.ee/lv/lt, justjoin.it, JobTech, ESCO, ЕЦБ, Eurostat. Особенно коммерческое использование и повторную публикацию текстов вакансий.
- [ ] **Bundesagentur:** ключ `jobboerse-jobsuche` в `app/integrations/bundesagentur.py` общий, но официального разрешения на такой доступ мы не видели. Проверить или убрать источник.
- [ ] **Повторить поиск секретов** по всей истории, потому что после этой проверки появятся новые коммиты: `gitleaks detect` или аналог.
- [ ] **Просмотреть историю коммитов и решить, оставлять ли её.** Один из вариантов — чистый старт: новый репозиторий без старой истории.
- [x] **Указать авторство:** кто что сделал. В истории есть строки `Co-Authored-By`, убрать их можно только переписыванием истории.

## Слияние с фронтендом

1. Слить PR бекенда по порядку: #1, #2, #3, через **Create a merge commit** (squash здесь создаст конфликты).
2. Фронтенд идёт в ветку `feature/frontend` от `main`, в папку `frontend/`.
3. Фронтенд читает адрес API из переменной окружения, а его собственный адрес добавляется в `CORS_ORIGINS` бекенда.
4. Добавить сервис `frontend` в `docker-compose.yml`, чтобы всё запускалось одной командой.
5. Проверить поиск, фильтры, страницы и карточку вакансии на настоящих данных, затем открыть PR в `main`.

- [ ] Авторское право возникает автоматически, регистрация не нужна. Добавить строку с обоими авторами: `Copyright (c) 2026 SatohyNo и skinnymaskboieshkere`.
- [ ] Выбрать вместе: MIT (другим можно почти всё), AGPL-3.0 (сервис на его основе должен открыть свой код) или без лицензии с «All rights reserved» (другие могут только смотреть).
- [ ] Помнить об ограничениях: данные вакансий принадлежат сайтам и работодателям, а защита кода, созданного ИИ, слабее и зависит от страны. Для коммерческого использования спросить юриста.
